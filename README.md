# 问道长生 - 修仙放置游戏

一款水墨宣纸风格的修仙题材放置类网页游戏。

## 游戏特色

### 🎨 视觉风格
- 宣纸白背景 + 水墨黑线条
- 暗金点缀，营造修仙氛围
- 历练时卷轴动画展开效果

### ⚔️ 核心玩法

#### 1. 灵根系统
- **9种灵根类型**：五行杂灵根、四灵根、三灵根、双灵根、单灵根、变异灵根、极品灵根、混沌灵根、无属性灵根
- **11种属性**：金、木、水、火、土、光、暗、冰、雷、风、毒
- **修炼加成**：不同灵根有不同修炼速度加成（0.6x - 2.0x）
- **特殊灵根**：
  - 无属性灵根：可修炼所有功法，但无加成
  - 混沌灵根：可修炼所有功法，且有2倍加成（最强）

#### 2. 境界系统

##### 凡人阶段
- 初始状态：100气血，0灵气，10攻击，2防御
- 需要外出历练寻找功法才能突破

##### 开元铸身境
- **练骨期**：强化206块骨骼
- **淬脉期**：淬炼十二正经
- **开元期**：开启窍穴，感应天地灵气
- **大境界突破加成**：气血+150，灵气+100，攻击+20，防御+8等
- **小境界突破加成**：气血+20，灵气+15，攻击+3等

##### 灵海化液境
- **化液期**：灵气化液，凝于丹田
- **凝河期**：液汇成河，奔流不息
- **聚海期**：河聚成海，浩瀚无垠
- **大境界突破加成**：气血+250，灵气+200，攻击+35等

##### 身化道台境
- **凝道期**：凝聚道台，奠定根基
- **分道期**：道台品质分级（一品~极道）
- **合道期**：筑神桥，合天地之道
- **大境界突破加成**：气血+400，灵气+350，攻击+50等

#### 3. 功法系统

##### 全属性功法（无属性要求）
- 凡品：《吐纳入门》、《静心诀》、《行气法》
- 灵品：《长生心经》
- 玄品：《无极功》

##### 五行功法
**金系**
- 凡品：《金锋诀》
- 灵品：《庚金锻体诀》
- 玄品：《太白剑经》

**木系**
- 凡品：《青木养元诀》
- 灵品：《万木长春功》
- 玄品：《青帝长生诀》

**水系**
- 凡品：《水镜诀》
- 灵品：《沧海诀》
- 玄品：《玄水天功》

**火系**
- 凡品：《炎阳诀》
- 灵品：《烈焰焚天功》
- 玄品：《太阳真火诀》

**土系**
- 凡品：《厚土诀》
- 灵品：《大地金身诀》
- 玄品：《山岳镇压经》

##### 变异属性功法
- **光系**：《照心真经》、《大光明经》
- **暗系**：《幽影秘典》、《幽冥鬼经》

#### 4. 历练系统

##### 历练地点
- **凡人境界**：青石镇外 · 破庙（可获得凡品物品）
- **开元境界**：云雾山道 · 灵泉（可获得凡品、灵品物品）

##### 历练事件
- 空手而归
- 采得草药 / 灵草
- 拾得残卷
- 遭遇山匪 / 妖兽
- 奇遇机缘

##### 掉落系统
- **货币**：灵石（1-25个）
- **材料**：止血草、凝神花、灵芝、千年人参、黑铁砂、精铁矿、寒铁、星辰石等
- **碎片**：丹方碎片、图纸碎片
- **功法**：功法残页、灵品功法残卷

#### 5. 炼丹系统

##### 丹方获取
- 收集40个丹方碎片 → 合成随机丹方
- 重复丹方可获得灵石补偿

##### 丹药种类
**凡品丹药**
- 回春丹：恢复50气血
- 回气丹：恢复30灵气
- 聚气丹：增加5%修为

**灵品丹药**
- 大回春丹：恢复150气血
- 大回气丹：恢复100灵气
- 破境丹：增加10%修为
- 力量丹：1小时内攻击+10

**玄品丹药**
- 造化丹：完全恢复气血
- 天元破障丹：突破成功率+20%

#### 6. 炼器系统

##### 图纸获取
- 收集6个图纸碎片 → 合成随机装备图纸
- 重复图纸可获得灵石补偿

##### 装备类型
- **武器**：铁剑、精铁剑、寒铁剑
- **护甲**：布甲、玄铁甲、星辰甲
- **法宝**：护身符、聚灵珠
- **灵饰**：灵玉佩

##### 装备属性
- 攻击、防御、气血、灵气
- 暴击、暴击伤害
- 速度、回复

#### 7. 背包系统

##### 物品分类
- **全部**：显示所有物品
- **装备**：武器、护甲、法宝、灵饰
- **丹药**：各种品质的丹药
- **材料**：草药、矿石、杂物
- **碎片**：丹方碎片、图纸碎片
- **功法**：功法残页、残卷
- **货币**：灵石

#### 8. 自动化系统

##### 自动打坐修炼
- 每5秒自动增加修为
- 修炼速度受灵根加成影响
- 有概率触发神识推演小游戏

##### 自动外出历练
- 每8秒自动完成一次历练
- 卷轴动画展开效果
- 随机获得物品和机缘
- 凡人有40%概率直接获得功法

#### 9. 故事剧情

##### 第一章：凡尘求机缘
- 目标：历练获得功法并修至入门
- 背景：青石镇外凡人寻求修仙之路

##### 第二章：铸身开元
- 目标：练骨淬脉，开元破境
- 内容：强化肉身，踏入修仙者行列

##### 第三章：灵海化液
- 目标：化液成河，凝聚灵海
- 内容：灵气修炼进入新阶段

##### 第四章：身化道台
- 目标：凝道台，悟天地之理
- 内容：奠定修仙根基，成为一方强者

## 游戏操作

### PC端
- **左侧面板**：先天命数、已习功法
- **中心区域**：修炼/历练主画面
- **右侧面板**：操作按钮、当前状态
- **底部日志**：游戏事件记录

### 移动端
- **底部标签栏**：修炼、历练、炼制、背包
- **侧边抽屉**：详细信息面板

## 技术栈
- **后端**：Python Flask + Supabase
- **前端**：HTML + TailwindCSS + Vanilla JS
- **风格**：宣纸水墨 + 暗金点缀
- **字体**：Noto Serif SC（思源宋体）

## 安装运行

1. 安装依赖
```bash
pip install -r requirements.txt
```

2. 配置环境变量（.env文件）
```
SUPABASE_URL=your_supabase_url
SUPABASE_SERVICE_ROLE_KEY=your_service_role_key
FLASK_SECRET_KEY=your_secret_key
PORT=8000
```

3. 运行游戏
```bash
python app.py
```

4. 浏览器访问
```
http://localhost:8000
```

## 游戏提示

1. **凡人阶段**：多去破庙历练，尽快获得第一个功法
2. **灵根选择**：混沌灵根最强但稀有，无属性灵根最灵活
3. **资源收集**：优先收集碎片合成丹方和图纸
4. **突破选择**：稳妥闭关100%成功，冒险突围75%成功但奖励略低
5. **材料管理**：留意稀有材料（千年人参、星辰石等）用于高级丹药和装备
